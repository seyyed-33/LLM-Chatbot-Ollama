# LLM Chatbot with Ollama and Llama 3.2

This project is a simple command-line chatbot built with Python. It connects to a local **Ollama** instance and uses the **Llama 3.2** model to generate responses.

## Features
- Local LLM inference (no internet needed after setup)
- Simple command-line interface
- Exit command with "goodbye"

## Technologies Used
- Python
- Requests
- Ollama
- Llama 3.2

## How to Run
1. Clone the repository
2. Make sure Ollama is running and the `llama3.2` model is available
3. Open the notebook:
   ```bash
   jupyter notebook llm_chatbot.ipynb
